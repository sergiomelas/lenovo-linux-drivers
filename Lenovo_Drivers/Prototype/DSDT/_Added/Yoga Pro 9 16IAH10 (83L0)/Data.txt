<h3 data-heading="What I found (for yogafan)">What I found (for yogafan)</h3>
<ul>
<li>The machine falls into the generic "Yoga" quirk (<code>\_SB.PCI0.LPC0.EC0.FANS</code>). There is no <code>FANS</code> / <code>FA1S</code> / <code>FA2S</code> / <code>FAN0</code> object in the DSDT or in any SSDT.</li>
<li><code>\_SB.PC00.LPCB.EC0</code> (<code>LCFC0002</code>) is an empty stub. The real EC is <code>\_SB.PC00.LPCB.H_EC</code> (SSDT "CB-01", <code>ssdt20</code> in the dump).</li>
<li>The EC region <code>ECF2</code> (EmbeddedControl) has no RPM field. The only fan-related field is <code>\_SB.PC00.LPCB.H_EC.FLVL</code> (EC offset <code>0x4A</code>), and no ACPI method reads it. It is a named field, so in principle a yogafan quirk could read it, but it looks like a fan level, not an RPM.</li>
<li>The other candidates don't help: <code>\_SB.VFAN._FST</code> returns a synthetic RPM (0 / 2500 / 3500 / 4500) chosen by <code>\_SB.FANL</code>, which only Windows sets via WMI. DPTF <code>TFN1._FST</code> calls an undefined method (<code>H_EC.DPTF.GFNS</code>). <code>ITE8</code> is disabled (<code>_STA</code> 0). Lenovo WMI (Other Mode) has no fan RPM attribute on this BIOS either. I tested this with Rong's series on the mailing list thread.</li>
</ul>
