BIOS: QGCN35WW. dsdt.dat is attached in the first comment. It was dumped with `sudo acpidump -b -n DSDT`, because this acpidump (20260408) has no `-t` option.

### Details

ACPI paths:
\_SB.PC00.LPCB.EC0.FA1S (EC offset 0x104, 8-bit)
\_SB.PC00.LPCB.EC0.FA2S (EC offset 0x137, 8-bit)

The current entry (yoga_pro_7_14iah10_cfg) points at \_SB.PC00.LPCB.EC0.FANS, which does not exist in this DSDT, so the driver returns -ENODEV with no message. The AML reads the fans as FA1S * 0x64 and FA2S * 0x64.

Tested configuration (reuses the existing loq_15iax9_8bit_dual_cfg):

```
static const struct yogafan_config loq_15iax9_8bit_dual_cfg = {
	.multiplier = 100,
	.fan_count = 2,
	.paths = { "\\_SB.PC00.LPCB.EC0.FA1S", "\\_SB.PC00.LPCB.EC0.FA2S" }
};
```

Result: both fans report through hwmon, 1500/1800 rpm at idle on the firmware curve, 0 when stopped, and up to 5100/5400 under stress-ng. The readings match the EC tach fields and the vendor WMI fan method.
