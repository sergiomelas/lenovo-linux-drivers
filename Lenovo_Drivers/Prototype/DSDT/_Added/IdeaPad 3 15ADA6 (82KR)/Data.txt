Hi!

yogafan can handle IdeaPad 3 15ADA6 using ``yoga_8bit_fans_cfg``.

At first I tried with ``ideapad_8bit_fan0_cfg``, like 15ALC6, but that doesn't work. acpi_get_handle() returns an error and no hwmon device gets created.

``yoga_8bit_fans_cfg`` works, a new hwmon device gets created and ``/sys/class/hwmon/hwmon5/fan1_input`` contains plausible values. ``sensors`` shows it too.

Tested on Arch Linux with kernel 7.2.2.
