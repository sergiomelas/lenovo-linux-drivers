========================================================================
PHASE 1: THE REBASE (Aligning with the Latest Kernel)
========================================================================
Do this BEFORE generating a patch to ensure your code works on the newest tree.

STEP 1: Update your local Git database from a virgen tree
        cd there the apply patch
1-  Official Linus Torvalds tree
  git fetch origin
2-  The Linux-Next tree
  git fetch next
3- Add the mantainers repo also of the section "Repos data" below

STEP 2: Create a fresh branch based on the LATEST code
git checkout -b yoga-v13-rebase next/master

STEP 3: Move your work to the new branch (Cherry-Pick)
# Get your old commit hash using 'git log old-branch'
git cherry-pick <your-old-commit-hash>

STEP 4: Resolve Conflicts
# If the Makefile or Kconfig changed in the new kernel, Git will stop.
# Edit the file to fix markers (<<<<<< HEAD), then:
git add <conflicted-file>
git cherry-pick --continue

========================================================================
PHASE 2: THE 6-FILE CHECKLIST (Integration Verification)
========================================================================

Before committing, verify all 6 points are correctly addressed in your tree:

[ ]  MAINTAINERS
(Contains your contact info and the list of files you are responsible for).

[ ]  Documentation/hwmon/index.rst
(The master list of documentation where you must add the name yogafan).

[ ] Documentation/hwmon/yogafan.rst
(The specific description of your driver and the RLLag filter).

[ ] drivers/hwmon/Kconfig
(The menu entry that allows users to select your driver during a kernel build).

[ ] drivers/hwmon/Makefile
(The instruction that tells the compiler to build yogafan.o).

[ ] drivers/hwmon/yogafan.c
(The actual C source code for the driver).



========================================================================
PHASE 3: PATCH GENERATION (THE FINAL EXPORT)
========================================================================

THE FULL BASELINE PATCH (MANUAL INJECTION)
--------------------------------------------------
# 1. Initialize the downloaded folder as a Git repo, download from kernel.org latest
     kernel (suppose here linux-7.0-rc6)
     Innstall all the patch alredy present in the repo to sincronize or sincronize the repo
# Run this inside your linux-7.0-rc6 folder
git init

# 2. Create an initial "Baseline" commit (This is the 'Virgin' state)
git add .
git commit -m "Baseline: Official Linux 7.0-rc6"

# 3. Create your clean export branch depending on the type of patch
git checkout -b yogafan_full_v13
git checkout -b yogafan_diff_v13

# 4. Physically copy your v13 files into the folders
# (Overwrite the existing ones or add the new ones)
# - MAINTAINERS
# - Documentation/hwmon/yogafan.rst
# - Documentation/hwmon/index.rst
# - drivers/hwmon/Kconfig
# - drivers/hwmon/Makefile
# - drivers/hwmon/yogafan.c


# 5. Force Git to recognize your changes (put al changed files here)
git add drivers/hwmon/yogafan.c \
        MAINTAINERS \
        Documentation/hwmon/yogafan.rst \
        Documentation/hwmon/index.rst \
        drivers/hwmon/Kconfig drivers/hwmon/Makefile

# 6. VERIFY: Ensure all modified  files are GREEN
git status

# 7. Commit with the PROFESSIONAL v13 message
git commit
# (Paste the finalized v13 text into the editor that opens)

# 8. Generate the FULL patch
git format-patch -1 -v13


========================================================================
PHASE 4: FINAL VALIDATION
========================================================================

# 1. Check for coding style errors (Strict mode):
./scripts/checkpatch.pl --strict v13-0001-hwmon-yogafan-Add-support...patch
./scripts/checkpatch.pl --file drivers/hwmon/yogafan.c


# 2. Verify Build (Run this inside the target kernel directory AFTER applying patch):
# To apply: git apply v13-0001-hwmon-yogafan...patch
scripts/config --module CONFIG_SENSORS_YOGAFAN
make olddefconfig
make drivers/hwmon/yogafan.ko

# 3. Verify Docs:
make htmldocs
