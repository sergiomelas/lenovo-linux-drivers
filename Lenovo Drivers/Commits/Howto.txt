========================================================================
PHASE 1: THE REBASE (Aligning with the Latest Kernel)
========================================================================
# 0. Start from the latest RC
# 1. Add the Linux-Next remote
git remote add linux-next https://git.kernel.org/pub/scm/linux/kernel/git/next/linux-next.git
git fetch linux-next

# Force updated of all remte references
git fetch --all

# Create a branch for yogafan
git checkout -b yoga-v1-final linux-next/master --force

# Verify yogafan is there
ls -l drivers/hwmon/yogafan.c

For other brach repos see below
========================================================================
PHASE 2: THE 6-FILE CHECKLIST (Integration Verification)
========================================================================

Before committing, verify all 6 points are correctly addressed in your tree:

[ ]  MAINTAINERS
(Contains your contact info and the list of files you are responsible for).

[ ]  Documentation/hwmon/index.rst
(The master list of documentation where you must add the name yogafan).

[ ] Documentation/hwmon/yogafan.rst
(The specific description of your driver and the RLLag filter).

[ ] drivers/hwmon/Kconfig
(The menu entry that allows users to select your driver during a kernel build).

[ ] drivers/hwmon/Makefile
(The instruction that tells the compiler to build yogafan.o).

[ ] drivers/hwmon/yogafan.c
(The actual C source code for the driver).


========================================================================
PHASE 3: PATCH GENERATION (THE FINAL EXPORT)
========================================================================

THE FULL BASELINE PATCH (MANUAL INJECTION)
--------------------------------------------------
# 0. If starting from a on line repo jump to 4

# 1. Initialize the downloaded folder as a Git repo, download from kernel.org
# Run this inside your linux-source folder (e.g., linux-7.1-rc1)

git init

# 2. Create an initial "Baseline" commit (This is the 'Virgin' state)
git add .
git commit -m "Baseline: Official Linux Source"

# 3. Create your clean export branch
git checkout -b yogafan_part2_v1-full
git checkout -b yogafan_new_v1-old_v11-diff

# 4. Physically copy your v1 files into the folders
# - MAINTAINERS
# - Documentation/hwmon/yogafan.rst
# - Documentation/hwmon/index.rst
# - drivers/hwmon/Kconfig
# - drivers/hwmon/Makefile
# - drivers/hwmon/yogafan.c

# 4.1 Clean the directory of any non-kernel files
make mrproper

# 5. Force Git to recognize your changes
git add drivers/hwmon/yogafan.c \
        MAINTAINERS \
        Documentation/hwmon/yogafan.rst \
        Documentation/hwmon/index.rst \
        drivers/hwmon/Kconfig drivers/hwmon/Makefile

# 6. VERIFY: Ensure all modified files are GREEN
     (ignore the millon of untraked files if coming from Phase 1)
git status

# 7. Commit with the PROFESSIONAL v1 message
git commit
# (Paste the finalized v1 text into the editor)

# 8. Generate the patch with the Part 2 suffix
git format-patch -1 --subject-prefix="PATCH v1"

========================================================================
PHASE 4: FINAL VALIDATION
========================================================================

# 1. Check for coding style and spelling errors:
./scripts/checkpatch.pl --strict --codespell v1-0001-hwmon-yogafan-Add-support...patch

# 2. Verify Build:
scripts/config --module CONFIG_SENSORS_YOGAFAN
make olddefconfig
make drivers/hwmon/yogafan.ko

# 3. Verify Docs:
make htmldocs
