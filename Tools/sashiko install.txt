================================================================================
LINUX KERNEL STATIC ANALYSIS SUITE (LOCAL SASHIKO) - DEBIAN SID
================================================================================

1. PREREQUISITES (CORE ENGINES)
--------------------------------------------------------------------------------
Install the primary semantic and structural analysis tools from Debian repos:

$ sudo apt update
$ sudo apt install sparse coccinelle build-essential libssl-dev libelf-dev \
                   sqlite3 libsqlite3-dev libgtk2.0-dev

2. SMATCH INSTALLATION (LOGIC & OVERFLOW ENGINE)
--------------------------------------------------------------------------------
Smatch must be built from source to track complex control flow paths:

$ git clone git://repo.or.cz/smatch.git
$ cd smatch
$ make
$ cd ..

3. LOCAL RUNNER SCRIPT (run_sashiko_local.sh)
--------------------------------------------------------------------------------
Create this script in your kernel root directory to automate the checks:

#!/bin/bash
DRIVER_PATH="drivers/hwmon/yogafan.c"
SMATCH_PATH="$HOME/smatch/smatch_scripts/kchecker"

echo "=== [1/3] CHECKPATCH (Formatting/Style) ==="
./scripts/checkpatch.pl --strict -f $DRIVER_PATH

echo -e "\n=== [2/3] SPARSE (Type Safety/Endianness) ==="
make C=1 CF="-Wbitwise -Wnon-pointer-null" drivers/hwmon/yogafan.o

echo -e "\n=== [3/3] SMATCH (Logic/Buffer Overflows) ==="
if [ -f "$SMATCH_PATH" ]; then
    $SMATCH_PATH $DRIVER_PATH
else
    echo "Error: Smatch kchecker not found at $SMATCH_PATH"
fi

4. USAGE INSTRUCTIONS
--------------------------------------------------------------------------------
1. Grant execution permissions:
   $ chmod +x run_sashiko_local.sh

2. Run the suite after every code change:
   $ ./run_sashiko_local.sh

5. HOW TO READ THE OUTPUT
--------------------------------------------------------------------------------
- [CHECKPATCH]: Fix "ERROR" and "WARNING". Aim for "total: 0 errors, 0 warnings".
- [SPARSE]: Look for "warning: cast to restricted...". Usually indicates a
            missing __le16 or __u32 type cast.
- [SMATCH]: Look for "error: buffer overflow" or "potential null dereference".
            These are the critical bugs (High/Medium) flagged by Sashiko-bot.

--------------------------------------------------------------------------------
NOTE: Running these locally on your Yoga 14cACN (Ryzen) allows you to catch
OOB (Out-of-Bounds) errors instantly by analyzing the Control Flow Graph (CFG)
before submitting to the mailing list.
