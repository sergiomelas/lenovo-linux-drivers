SASHIKO LOCAL: COMPLETE INSTALLATION & USAGE HOWTO (2026)
Author: Sergio Melas <sergiomelas@gmail.com>
================================================================================

This guide documents the real, verified local setup for the official Rust-based
Sashiko AI Linux kernel reviewer (https://sashiko.dev / sashiko v0.9.5+)
paired with local static checks (checkpatch.pl, sparse, htmldocs).

--------------------------------------------------------------------------------
1. PREREQUISITES (DEBIAN / UBUNTU)
--------------------------------------------------------------------------------
Make sure Git, Rust/Cargo (1.90+), and Sparse are installed:

  $ sudo apt update
  $ sudo apt install -y git cargo rustc sparse

Verify:
  $ rustc --version
  $ cargo --version
  $ which sparse

--------------------------------------------------------------------------------
2. INSTALL OFFICIAL SASHIKO CLI (CRATES.IO)
--------------------------------------------------------------------------------
Install the official Sashiko binaries (`sashiko` and `sashiko-cli`) into
`~/.cargo/bin/`:

  $ cargo install sashiko

Add `~/.cargo/bin` permanently to your PATH:

  $ echo 'export PATH="$HOME/.cargo/bin:$PATH"' >> ~/.bashrc
  $ source ~/.bashrc

Verify installation:
  $ sashiko --version

--------------------------------------------------------------------------------
3. INITIALIZE CONFIGURATION & KERNEL PROMPTS
--------------------------------------------------------------------------------
Run once to create `~/.config/sashiko.toml` and install the official kernel
review prompts in `~/.local/share/sashiko/prompts/`:

  $ sashiko init

Example `~/.config/sashiko.toml`:

  [ai]
  provider = "gemini"
  model = "gemini-3.8-flash"
  max_input_tokens = 900000

  [review]
  concurrency = 4

NOTE ON FREE-TIER QUOTA:
- The default model written by `sashiko init` (`gemini-4-argon`) may report
  Free Tier daily quota exceeded.
- Use `gemini-3.8-flash` (either in `~/.config/sashiko.toml` or via
  `-m gemini-3.8-flash`) for Free Tier Gemini API keys.

--------------------------------------------------------------------------------
4. API KEY CONFIGURATION (NEVER COMMIT KEYS TO GIT!)
--------------------------------------------------------------------------------
Get a Gemini API key from Google AI Studio: https://aistudio.google.com/api-keys

Option A — Export for the current terminal session:
  $ export LLM_API_KEY="YOUR_GEMINI_API_KEY"
  $ export GEMINI_API_KEY="$LLM_API_KEY"

Option B — Load silently from a local key file (e.g. in Tools/SasHiko/Key/):
  $ export LLM_API_KEY="$(tr -d ' \t\r\n' < /path/to/your_key_file)"
  $ export GEMINI_API_KEY="$LLM_API_KEY"

Option C — Persist in `~/.bashrc` (outside the Git repository):
  $ echo 'export LLM_API_KEY="YOUR_GEMINI_API_KEY"' >> ~/.bashrc
  $ source ~/.bashrc

--------------------------------------------------------------------------------
5. RUNNING LOCAL STATIC CHECKS + SASHIKO REVIEW ON YOGAFAN PATCHES
--------------------------------------------------------------------------------
Move into the working kernel tree where your commits sit on top of hwmon-next:

  $ cd /home/sergio/Others/Kernel-Upstream-Development/_Patch-Builtd/linux-guenter-last/linux-guenter-last

Step 1 — Checkpatch (style & spelling, skip 0000-cover-letter.patch):
  $ ./scripts/checkpatch.pl --strict --codespell ../000[1-9]-hwmon-yogafan-*.patch

Step 2 — Sparse + Compiler W=1 (type safety, endianness, strict warnings):
  $ rm -f drivers/hwmon/yogafan.o
  $ make C=1 CF="-Wbitwise -Wnon-pointer-null" W=1 drivers/hwmon/yogafan.o

Step 3 — Documentation check (hwmon-only Sphinx build):
  $ make SPHINXDIRS=hwmon htmldocs

Step 4 — Sashiko AI review on your commit range (e.g. last 2 commits):
  $ sashiko review --project linux -m gemini-3.8-flash HEAD~2..HEAD

Useful Sashiko flags:
  --cheap    : Combine exploratory stages to reduce latency and API calls
  --no-ai    : Validate patch extraction/application only (no API calls)
  --resume   : Resume an interrupted review from recorded answers
  --design   : Add series-level design assessment alongside bug review
